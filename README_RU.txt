PLENKA3 — Android-проект
========================

Это Android-оболочка для переданного приложения «Подбор плёнки».
Название приложения: Plenka3.
Реклама и рекламные SDK отсутствуют.

Что реализовано:
- приложение открывается сразу в режиме редактирования;
- изменения параметров и избранное автоматически сохраняются в локальном хранилище приложения;
- данные остаются на телефоне после закрытия и повторного запуска;
- кнопка «Экспортировать данные» позволяет сохранить резервную копию data.js через системный диалог Android;
- интерфейс и расчёты исходного справочника сохранены;
- иконка приложения сделана из логотипа пользователя;
- содержимое приложения встроено в APK, поэтому для работы интернет не нужен.

Сборка APK
----------
В проект добавлен автоматический сценарий GitHub Actions. Подробная инструкция
находится в файле BUILD_APK_RU.txt. Он позволяет собрать APK на сервере GitHub
без установки Android Studio на компьютер. Для локальной сборки можно открыть
папку проекта в Android Studio и выбрать Build → Build Bundle(s) / APK(s) → Build APK(s).

Требования: JDK 17 или новее, Android SDK Platform 35, Android Gradle Plugin 8.7.3.

Важно о сохранении:
- обычное редактирование сохраняется автоматически на этом устройстве;
- экспорт data.js нужен для резервной копии/переноса данных;
- если очистить данные приложения или удалить его, локальные изменения могут быть потеряны.
- исходный справочник содержит заполненные значения только для сочетаний:
  1500 мм / Д-30, Д-35, Д-40 и 1200 мм / Д-30. Остальные строки каталога
  присутствуют, но значения в исходном файле не заполнены.

APK в этой среде пока не собран: Android SDK и Gradle здесь не установлены.
Автоматический сценарий сборки добавлен, но его необходимо запустить в GitHub Actions.
Это исходный Android-проект, а не готовый APK.
