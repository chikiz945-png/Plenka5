КАК ПОЛУЧИТЬ APK PLENKA3 БЕЗ ANDROID STUDIO
===========================================

В проект добавлен автоматический сценарий сборки для GitHub Actions.
Он собирает debug APK на сервере GitHub и прикладывает APK к запуску сборки.

1. Распакуйте Plenka3-Android-Project.zip на компьютере.
2. Откройте github.com и войдите в свой аккаунт (если аккаунта нет — создайте).
3. Создайте новый репозиторий, например Plenka3. Для личного проекта можно выбрать Private.
4. Загрузите в репозиторий ВСЁ содержимое папки Plenka3-Android, включая скрытую папку .github.
   Важно: файл .github/workflows/build-apk.yml должен оказаться именно по этому пути.
5. Откройте в репозитории вкладку Actions.
6. Выберите "Build Plenka3 APK" и нажмите "Run workflow" (если сборка не стартировала сама).
7. Дождитесь зелёного статуса завершения сборки.
8. Откройте завершённый запуск и внизу страницы скачайте Artifact
   "Plenka3-debug-apk". Распакуйте скачанный ZIP — внутри будет app-debug.apk.
9. Передайте APK на телефон, откройте его и разрешите установку из этого источника,
   если Android попросит.

ПРИМЕЧАНИЯ
----------
- Это debug APK для установки и проверки, не релизная подписанная версия.
- APK ещё не собран и не проверен на физическом телефоне.
- Для установки поверх предыдущей сборки подпись должна совпадать; при несовпадении
  Android может потребовать удалить старую версию. Удаление приложения может удалить
  локально сохранённые данные — сначала экспортируйте резервную копию.
- Сборка использует Android Gradle Plugin 8.7.3, Gradle 8.9, JDK 17 и Android SDK 35.
